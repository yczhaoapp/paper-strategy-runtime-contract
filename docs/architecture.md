# 架构与信任边界

## 为什么增加论文层

`psrc.papers` 将实际原文、声明式复现映射、生成代码、市场输入、训练产物和回测证据串在同一条可复核链上。运行契约 1.1.0 与论文解析器独立演进，保持线格式兼容。

## 模块

| 模块 | 职责 | 拒绝条件 |
| --- | --- | --- |
| `papers.ingest` | 本地 PDF/HTML/文本解析，原文和页级哈希 | 扫描 PDF 无文字、加密、超限、格式错误 |
| `papers.models` | 原文、来源注册、18 策略绑定、claim-code-test 映射、行为签名、recipe、数据证据与复现规格的严格 Schema | 未知字段、算法类型不符、映射不完整、重复证据 ID |
| `papers.catalog` | 重算 18 个论文/声明/实现/测试/运行行为绑定 | 来源、锚点、代码哈希、测试未执行、行为漂移、策略类别或覆盖数量不符 |
| `papers.compiler` | 来源匹配、页内定位、参数检查，确定性生成包 | 原文错版、证据缺失、参数非法、旧输出污染 |
| `papers.algorithms` | 可独立数学测试的规则、MLE、Bellman 核心 | 未定义输入、完全分离、训练不收敛、缺失状态 |
| `papers.data` | 固定公开历史数据、显式合成市场、因果标签、时间划分、反事实训练环境 | 数据哈希改变、同 bar 前视、跨训练边界取标签 |
| `papers.strategies` | 算法到训练/推理/订单的统一实现 | 模型未加载、产物来源错配、未知 RL 状态 |
| `papers.pipeline` | 从原始论文执行到报告 | 任何阶段错误都不替代引擎或输入 |
| `papers.evidence` | 从原始来源重新构建包并对照产物 | 代码、来源、参数、模型、报告任一改变 |
| `contract/runtime/adapters` | 保留的引擎中立运行契约 | 字段/粒度/符号/动作/能力/隔离不满足 |

## 确定性和语义审阅

recipe 与 binding 是人审的论文本体到算法映射，不是 LLM 自评分。短锚点证明所指页确实存在相应段落，不能单独证明解释正确；公式解释由明确的代码、代码哈希和独立数值测试约束。报告保留 `mapping_review`、`assumptions`、`deviations` 和忠实度等级，不将近似或替代数据隐藏起来。

生成源码仅引用固定算法类，并嵌入经严格 Schema 校验的 manifest 和数值参数。论文正文和解释字段不会进入 eval/exec。不支持的算法需要增加后端，不能把一个接近的内置策略当作成功复现。

## 时间与训练

输入具有事件时间、可用时间、接收时间。Reference 先结算上一事件的订单，再向策略提供当前事件；Backtrader 使用下一 bar 的真实 broker 回调。监督样本的特征与标签全部来自训练分区，标签定义为下一个非零中价变化，丢弃训练末端无法标注的观察。训练矩阵及原始分区哈希都随包保存。

RL 对训练报价枚举私有时间、库存和动作，按剩余时间递增进行经验 Bellman 更新。费用与下一事件撮合与参考环境一致。截止强制市价成交在声明中固定；未知状态是错误，不使用最近邻替代。该论文案例与目录中的合成 RL 示例采用不同的状态语义，并在绑定中分别声明。

## 沙箱

开发模式不是安全边界。外部任意 Python 包应在严格容器中执行。容器需要同时证明非 root、真实容器标记、无网卡、能力清零、NoNewPrivs、只读根目录及 noexec/nosuid/nodev 临时目录。调用命令另外声明 CPU、内存、PID、超时限制。静态 import/文件/反射扫描只作为额外防线，不宣称能防御所有 Python 逃逸。

论文解析也是处理不可信输入。限制原文件 20 MiB、页数 200、提取文本 2M 字符；生产处理恶意 PDF 应使用严格容器的资源边界，宿主解析上限不等价于抗解压炸弹隔离。

## 环境与验收

在线准备只负责安装锁定依赖和获取固定哈希原文。离线运行仅调用已安装解释器，不调用包管理器。验收在新的临时证据目录运行，每步记录退出码和日志，再复制本次产物到指定输出。任何失败将覆盖总验收状态为失败，防止旧成功报告误导。

默认验证两个实际引擎；可选 Nautilus 的缺失不触发替代，也不被报告为已运行。Linux 严格容器与 Windows/macOS 宿主验收分别保留记录。
